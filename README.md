## English

**BigO.dev** is a premium educational platform designed to help students and developers master data structures and algorithms through interactive visualizations, detailed technical sheets, and rigorous complexity analysis.

### Key Features
- **Interactive Visualizer**: Step-by-step execution of sorting, searching, and tree algorithms.
- **Complexity Overview**: Clear distinctions between **O** (Upper), **Ω** (Lower), and **Θ** (Exact) notations.
- **Technical Sheets**: Detailed proofs of termination and correctness for every algorithm.
- **Multi-Theme System**: 7+ premium color palettes with glassmorphism aesthetics.
- **Localization**: Full support for English and French.

### Tech Stack
- **Framework**: React 19 + Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS + CSS Variables (Theme System)
- **Icons**: Lucide React

### Getting Started
1. **Clone the repo**: `git clone https://github.com/ManonGras/BigO.dev.git`
2. **Install dependencies**: `npm install`
3. **Run locally**: `npm run dev`

### Deployment
Built-in **GitHub Actions** pipeline for automatic deployment to GitHub Pages.
1. Enable **GitHub Actions** in Settings > Pages.
2. Every push to the `main` branch will automatically trigger a build, run type checking, and deploy your site to GitHub Pages.

## Français

**BigO.dev** est une plateforme éducative premium conçue pour aider les étudiants et développeurs à maîtriser les structures de données et les algorithmes via des visualisations interactives et des analyses de complexité rigoureuses.

### Fonctionnalités Clés
- **Visualiseur Interactif** : Exécution pas à pas des algorithmes de tri, recherche et arbres.
- **Récapitulatif de Complexité** : Distinctions claires entre les notations **O** (Supérieure), **Ω** (Inférieure), et **Θ** (Exacte).
- **Fiches Techniques** : Preuves de terminaison et de correction détaillées.
- **Système Multi-Thèmes** : Plus de 7 palettes de couleurs premium.
- **Localisation** : Support complet de l'Anglais et du Français.

### Stack Technique
- **Framework** : React 19 + Vite
- **Langage** : TypeScript
- **Style** : Tailwind CSS + Variables CSS
- **Icônes** : Lucide React

### Démarrer
1. **Cloner le repo** : `git clone https://github.com/ManonGras/BigO.dev.git`
2. **Installer les dépendances** : `npm install`
3. **Lancer en local** : `npm run dev`

### Déploiement
Pipeline **GitHub Actions** intégrée pour un déploiement automatique sur GitHub Pages.
1. Activez **GitHub Actions** dans Settings > Pages.
2. Chaque push sur la branche `main` déclenchera automatiquement un build, une vérification des types et le déploiement sur GitHub Pages.
